## HOW TO JUDGE
- An element is corrupted when it audibly hurts the result: harsh or muddy tone, over-compressed/pumping or spiky dynamics, chopped notes or gate artifacts, distortion that doesn't belong, drowning reverb/delay, sitting far too loud/quiet or in the wrong stereo place compared with how it sits in the Reference.
- The Reference is the SAME SONG (a different excerpt) -- use it as the target for how each element should sound and sit. Ignore overall loudness (clips are loudness-normalized) and ignore that solo elements sound bare on their own; judge problems that survive in the full render.
- Be strict but fair: flag ONLY elements with a real, fixable problem. Returning an EMPTY list is a normal, expected outcome -- endless revision is a failure mode, not diligence.
- Check the revision history: if an element was already revised for the same complaint and still sounds the same, do not flag it again for that reason -- either flag a different element that attacks the problem another way, or leave it out.
- Order matters: put the WORST element first; it is the one that gets fixed this round.
